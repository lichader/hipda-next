# Favorites fixtures

`add-real.xml` and `remove-real.xml` are the forum's replies to adding a thread to favorites and removing it (`my.php?item=favorites&action=add|remove&inajax=1`), captured on 2026-11-28 with the debug response recorder. They hold no personal data. The list's delete form answers with the favorites page, which the app ignores, so it isn't kept.
